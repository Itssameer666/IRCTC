A PNR (Passenger Name Record) is a unique 10-digit number assigned to every railway reservation. You can enter this 10-digit number in our PNR Status tool above to view live coach allocation, seat numbers, and journey schedule.

RailNova implements the official gateway architecture (Razorpay standard). The backend generates a secure Order ID, the checkout simulates payment completion, and the server validates the HMAC-SHA256 signature before booking status is marked as CONFIRMED.

Confirmed tickets can be cancelled directly through your dashboard. Standard cancellation fee is ₹120 per passenger or 20% of fare (whichever is higher). The refund amount is credited immediately back to your original source.
